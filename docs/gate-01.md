### 발견: 질문 탭 확장 후 작은 창 위치가 바뀜

- 현상(사용자 보고): 작은 창을 화면 모서리에 두고 질문 탭(380×480)을 누른 뒤 응답 탭(240×160)으로 돌아오면 원래 자리로 돌아가지 않음.
- 원인 추정: 화면 가장자리 근처에서 창이 커지면 Chrome이 화면 밖으로 나가지 않게 창을 안쪽으로 옮기고, 다시 작아져도 옮겨진 위치를 유지.
- 제약: Chrome 공식 문서 "The Picture-in-Picture window position cannot be set by the website." → 코드로 원래 위치 복원 불가.
- 처리: 사용자에게 대안 선택 요청 (STATUS 열린 질문).

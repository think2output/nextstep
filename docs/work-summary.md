## 1. 한 줄 소개

젭 + VS Code로 실습하는 수강생이 화면 위에 떠 있는 **작은 창**(Chrome Document Picture-in-Picture)에서 강사의 확인 요청에 한 번 클릭으로 응답하고 익명으로 질문한다. 강사는 같은 작은 창에서 응답 집계를 보고, 원래 탭에서 수업 리포트를 본다.

- 배포 주소: https://nextstep-smoky.vercel.app
- 저장소: https://github.com/think2output/nextstep
- 요구사항: `docs/PRD.md` v1.12

## 2. 화면과 기능 (지금 모습)

### 학생

| 화면 | 기능 |
|---|---|
| 방 입장 | 참여 코드·링크로 입장 → “👇 먼저 작은 창을 띄워주세요” 안내 상자. 웹 화면은 원할 때만 펼침 (D-034) |
| 작은 창 · 응답 | 200×120으로 시작, ＋로 240×160 (D-038). 요청이 오면 버튼 두 개. 서버가 받은 뒤에만 버튼이 진한 파랑 + “✓ 전송 완료” 잠깐 (RESP-04, D-032·D-036) |
| 작은 창 · 재촉 | 미응답이면 빨간 테두리 3번 깜빡임 + 알림음(끌 수 있음) (D-028) |
| 작은 창 · 질문 | “익명으로 질문해요” 입력칸 하나로 비슷한 질문 찾기 + 남기기, ✉ 보내기·⇅ 정렬, 공감 +N, 내 질문 me (D-041·D-042) |
| 옆 질문 보기 창 | 질문 줄을 누르면 작은 창 옆 빈 쪽에 원문 + “저도 궁금해요 +N” (D-042) |
| 연결 끊김 | 바로 주황 테두리·“다시 연결하는 중…” 띠 → 20초 넘으면 덮개 + 큰 ‘다시 연결’ (D-043) |

### 강사

| 화면 | 기능 |
|---|---|
| 방 만들기 | 수업명 + 운영자 코드(파일럿 코드) → 참여 코드·링크·복사. 정원 학생 50명 (D-045). 운영자 코드는 `npm run pilot:new`/`pilot:set`으로 바꿈 (D-046) |
| 작은 창 · 응답 | 준비/이해/진행 확인 보내기, “N/M명 응답”, 인원·%·50% 막대, 🔔 재촉, 확인 종료(파란 버튼) (D-037·D-040) |
| 작은 창 · 질문 | 미답변/답변 완료, 공감 많은 순/최신순, ✓ 답변 완료(연한 파랑) |
| 옆 질문 보기 창 | 원문, 답변 완료/미답변으로, 숨기기 |
| 원래 탭 · 수업 리포트 | 숫자 카드(확인 횟수·평균 응답률·대기가 과반·미답변 질문), 확인별 긍정 % 막대, 누른 확인 하나의 자세한 결과, 접힌 전체 목록 (D-044) |

### 지키는 원칙 (CLAUDE.md 절대 규칙)

- 실제 다른 컴퓨터끼리 통신(Supabase). 학생에게 다른 학생 선택·집계를 주지 않고, 강사에게도 개별 응답·작성자·미응답자 신원을 주지 않는다.
- 미응답은 yes/no가 아니다. 분모는 요청 시작 때 고정한 대상 인원.
- 서버 승인 전에는 “전송 완료”를 보이지 않는다.
- 작은 창이 포커스를 빼앗거나 스스로 열리거나 크기를 바꾸지 않는다. 깜빡임은 재촉과 연결 끊김(20초 넘김)에만.
- 원래 탭·작은 창·옆 창이 서버 연결 하나를 같이 쓴다(옆 창은 원래 탭이 그려 넣음).

## 5. AI가 틀렸다가 고친 사례 (발표 “AI 수정 사례”용, 원문은 `docs/ai-log.md`)

| 사례 | 무엇이 틀렸나 | 어떻게 찾았나 |
|---|---|---|
| 강사 작은 창 “묘한 스크롤” | 공간이 모자라면 제목·연결 줄이 높이 0으로 찌그러져 숨고, 넘침 측정도 0으로 나와 놓침 | 사용자 실기 → 사진에서 제목 줄이 없음을 발견 |
| 클릭 순간 스크롤 | 200×120에서 “전송 중…” 줄이 생기는 순간을 측정에서 빼먹음 | 사용자 실기 → 응답을 일부러 늦춰 측정 |
| 끊김 감지 “20초”가 실제 39초 | heartbeat(15초)에만 의존 | 오프라인 흉내로 시간을 재서 발견 → offline 이벤트로 즉시 감지 |
| 리포트 막대가 안 눌림 | 50% 점선이 막대 위를 덮음 | 사진 스크립트의 hover 실패 |
| 시험 스크립트 버튼 오인 | 리포트 막대 이름에 ‘준비 확인’이 들어가 부분 일치 | strict mode 오류 |

교훈: 화면 변경은 “평상시”만이 아니라 전송 중·끊김 같은 **순간 상태**까지, 그리고 **두 크기**에서 재야 한다. 숫자가 0이라도 사진으로 본다.

## 6. 알려진 한계

- 옆 질문 보기 창은 항상 위가 아니다(브라우저가 작은 창을 페이지당 하나만 허용).
- 200×120 질문 탭은 목록이 약 1.5줄. ＋로 키워 본다.
- 작은 창에 대상 인원은 “N/M명 응답”으로만, 과반 문구는 리포트에만.
- 학생은 답변 완료된 질문 목록을 볼 수 없다. 질문 50개 초과 ‘더 보기’ 없음.
- 배포 주소 smoke 첫 실패 1회는 원인 미확정(이후 재현 안 됨).
